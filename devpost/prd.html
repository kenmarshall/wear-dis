Outfit Advisor

Describe an event, answer a few tailored questions, get about five ranked outfits that explain why they work, with Amazon links for every piece. (working name)

How the scope grew

Scope: "describe an event in plain words"
→
A text box and tappable event categories, so it's easy to start either way
Scope: "a few short follow-up questions"
→
The advisor picks event-specific questions with tap-to-choose answers, plus "about you" every time
Scope: "five ranked outfit cards"
→
Every piece visible on one card; click to expand in place for the "why" and the links
Scope: (no states defined)
→
A loading animation, plus friendly try-again guidance for bad input and for failures

The journey

Click a step in the diagram or the buttons to see its behavior, edge states, and how we'll know it works.

Look and feel

Date Night

Light and minimal, with lots of white space. Typography that "feels stylistic like going into a fashion store," something that makes you "feel like a fashion model." The swatches are the main color; the rest of the UI stays quiet. (The type and swatches above are an illustration, not final picks.)

Building now vs. later

NOW What we're building
  • A start step with a text box and tappable event categories
  • Tailored follow-ups with tap-to-choose options, including "about you" every time
  • A loading animation
  • About five ranked outfit cards, each showing every piece with color swatches
  • Expand in place to show the "why this works" and an Amazon search link per piece
  • Friendly states for unusable input and failures, with guidance and a retry
DEFERRED Implied, but not now
  • Saving "about you": needs memory between visits plus a way to view and edit it, and doesn't prove the kernel
  • Prices and an outfit total: needs real product data, which the scope cut
  • Later: outfit images or you in the outfit, using your own wardrobe, style options as a choice
NON-GOALS Won't do
  • Exact products through Amazon's API
  • Photos or AI images in the PoC
  • Accounts or sign-in
  • Wardrobe management
ASSUMED Not your decisions yet, open to change
  • About six event categories (date night, concert, wedding guest, work event, party, casual outing)
  • Follow-ups appear together on one step, around three to five questions
  • A "start over" action on results
  • Open question: the project name (doesn't block the spec)
