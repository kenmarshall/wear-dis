Outfit Advisor

Next.js on your laptop · Claude Opus 5.5 for questions and outfits · Amazon search links built in code · nothing stored.

Three pieces, in plain language

The page

One browser screen that moves through Start → Follow-ups → Loading → Results. It's React components with CSS, and it remembers answers only while the tab is open.

Two API routes

Small server files that hold your secret key and ask Claude for (1) follow-up questions and (2) five ranked outfits. Claude must answer in a fixed JSON shape, and our code checks it.

Link builder

Our own function turns each piece into amazon.com/s?k=navy+slim+fit+blazer+men. The AI never makes links, so they're free, instant, and never broken.

Data shapes

Defined once in lib/schemas.ts (zod). Claude must match them, and TypeScript types come from them.

QuestionsResponse { usable, guidance | null, exampleEvent | null, questions: Question[] }
Question          { id, text, options: string[] }            // 2–5 options
OutfitsResponse   { outfits: Outfit[] }                       // exactly 5
Outfit            { rank, name, summary, whyOccasion, whyColors, pieces: Piece[] }
Piece             { slot, name, colorName, colorHex, searchTerms }

Where data lives: React state in the page only. Close the tab and everything is gone, which matches the PRD (nothing is saved).

Decisions

yours Learner decisions
  • Next.js over Expo web: familiar React plus a built-in server for the key (accepted a small learning curve)
  • Claude Opus 5.5: best taste for the kernel (accepted ~7¢ per session and a slower outfit step)
  • Local only: "since it cost, maybe just locally for now"
derived My implementation details, change any you like
  • Two routes (questions, then outfits) with structured outputs via zod
  • Effort low for questions, medium for outfits
  • Server-side refusal fallback enabled (to verify with messages.parse)
  • Fixed Men's/Women's question in code, so links are always right
  • CSS Modules + tokens.css; Bodoni Moda + Inter
  • Categories: Date night, Concert, Wedding guest, Work event, Party, Casual outing
  • Vitest for the link builder and schemas
check early Build-time checks
  1. Real Opus 5.5 time for the outfit call. If it's far past 30s, we discuss effort before changing the model
  2. Do the Amazon search links land on relevant, correctly colored results?
  3. Current Next.js version; fallbacks with messages.parse

Learner uncertainty: none identified ("I think I understand everything"). Project name is still open and doesn't block the build.
